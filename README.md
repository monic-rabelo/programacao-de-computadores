# Prisma System

Sistema que consiste no cadastramento de notas de alunos de uma instituição, de cada matéria e bimestre, para ver se foi aprovado ou reprovado.

## Etapas

O projeto foi dividido em 5 etapas, onde cada uma acrescenta métodos e funções diferentes no código.

### Estrutura Sequencial

Entrada e saída de dados, variáveis e operadores.
* Coletar dados básicos;
* Calcular média simples;
* Exibir resultados no console.

---

### Estrutura de Decisão

`if`, `else` e `elif`.
* Aplicar critérios de aprovação;
* Verificar nota mínima;
* Verificar frequência.

---

### Estrutura de Repetição

`for` e `while`.
* Permitir cadastro de múltiplas disciplinas;
* Repetir entradas de dados;
* Validar informações.

---

### Estrutura de Dados

Listas e dicionários.
* Armazenar disciplinas, notas e faltas;
* Processar os dados cadastrados.

---

## Modularização

Criação e uso de funções (`def`).
* Cadastro de dados;
* Cálculo de nota;
* Cálculo de frequência;
* Geração do relatório final.
